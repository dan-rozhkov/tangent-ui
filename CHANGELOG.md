# Changelog

All notable changes to Tangent UI are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the registry follows [semantic versioning](https://semver.org). See [CONTRIBUTING.md](CONTRIBUTING.md#versioning-and-deprecation) for the deprecation policy.

## [Unreleased]

### Added

- `/tokens.json`: design tokens in the W3C DTCG shape, with light, dark and accent modes in `$extensions["tangent.modes"]`. Generated by `npm run gen:tokens`.
- shadcn registry at `/r/registry.json` and `/r/<name>.json` under the `@tangent` namespace, plus `/llms.txt` for agents. Generated by `npm run gen:registry`.
- `npm run audit:tokens`: fails when hardcoded colors, default-palette utilities or raw easing grow in any file under `components/ui`, checked against `scripts/token-audit-baseline.json`.
- `CONTRIBUTING.md` with conventions, the versioning policy and the deprecation policy.
- Issue forms for component requests and bug reports, and a pull request template.
- Color tokens `--shade` and `--sheen` (theme-invariant black and white inks for shadows, scrims and highlights, used with alpha), `--on-media` for text over photos, and `--syntax-*` for code highlighting.
- `token-audit-ignore: <reason>` marks a deliberate literal (brand mark, mask alpha, art material). Exempt hits are still listed by the audit.

### Changed

- Components use color tokens instead of literal colors, with no visible change; the token audit baseline now holds only motion hits.
- Foundation shadows mix `--shade` instead of a literal black.
- The token audit counts hex colors inside Tailwind arbitrary values (`#b9c2ff_70%`) and skips mask lines, whose colors only carry alpha.

## [0.0.1]

First tracked state of the library.

### Added

- About 150 components and blocks in `components/ui`, built on Base UI, Tailwind CSS v4 and Motion, each with a live demo.
- Design tokens in `app/foundation.css`: color, surface, radius, shadow and accent, with light and dark themes.
- Shared motion tokens in `lib/motion-tokens.ts` and shared gesture physics in `lib/gesture.ts`.
- Gallery site with a component search, a fullscreen menu, global motion settings and scripted autoplay tours.
- Phosphor icons at the regular weight across the library.
